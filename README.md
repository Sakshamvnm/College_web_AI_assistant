# College_web_AI_assistant
An AI assistant helping college enthusiasts to know about the college they are about to enter.

Since the github is not a storage and a maximum of 25MB of data can't be uploaded so the LLM model couldn't be uploaded.

We used _Qwen2.5-0.5B-Instruct-Q4_K_M_ a 2.5B-0.5B parameter model . You can use any model but for a college chatbot this model was perfect with a 0.5B parameter.
Steps needed to follow-:
1) Keep the model in the models folder inside config.
2) Install necessary django tools in a venv
3) Install django on your computer
4) Install the model from https://huggingface.co/collections/HuggingFaceTB/smollm2
